# Kitty Backend v8.32

Installer downloads used by Kitty Download Manager. Choose Linux (`install.sh`), Windows x64 (`Install.cmd`) or macOS (`Install.command`) after extracting the matching ZIP. Source and GNU GPL v3.0 license: [main repository](https://github.com/sususususmomo/kitty-download-manager-releases). This backend adds thumbnail/cover downloads for the Image only mode in frontend v8.38.

Téléchargements des installateurs utilisés par Kitty Download Manager. Après extraction du ZIP adapté, lancer `install.sh` sur Linux, `Install.cmd` sur Windows x64 ou `Install.command` sur macOS. Code source et licence GNU GPL v3.0 : [dépôt principal](https://github.com/sususususmomo/kitty-download-manager-releases). Ce backend permet de télécharger les miniatures et pochettes avec le mode Image uniquement de l’extension v8.38.
