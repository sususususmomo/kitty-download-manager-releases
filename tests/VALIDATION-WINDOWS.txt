Erreurs V8.26 traitées :
- Le test du lanceur passait des guillemets doubles au sérialiseur C de Python.
  CMD recevait des guillemets précédés de backslashes et refusait le batch.
  Le test utilise maintenant le nom relatif fixe .\native-host.bat, avec le
  dossier de travail passé séparément à CreateProcess.
- La désinstallation supprimait deux fois une clé HKCU partagée entre les
  vues 32/64 bits du registre. La seconde suppression levait FileNotFoundError.
  Le cas a été reproduit dans un test portable avant correction. La clé déjà
  absente est désormais acceptée; les autres erreurs restaurent le registre.
- La collection foreach du script PowerShell de nettoyage est parenthésée.
- Le test final attend la suppression effective des runtimes, du script de
  nettoyage et de Uninstall.cmd.
